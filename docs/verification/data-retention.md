# 中断、断网与数据保留

2026-11-19，任务 8.4。

新增独立子进程故障测试：子进程建立项目与选中状态、导入资料、页面采集、已批准原型、未批准候选、状态截图、本地草稿和待核对发布记录；写入原型任务检查点后，在未提交事务中删除批准与候选，并用 SIGKILL 终止自身。父进程重新打开同一 SQLite 和工作空间。

验证结果：

- SQLite 回滚未提交删除，原有两个版本与批准保留，项目选中状态和资料索引仍可读取。
- 清理残留临时文件后，已保存工作空间所有文件哈希保持不变。
- 原型任务变为 interrupted，发布记录展示 needs-check，重启读取没有调用模型或平台。
- 显式重试时模拟断网，旧成果哈希不变，失败只新增对应任务记录。
- 从基线恢复创建新的未批准候选，旧基线内容与批准不变。
- 随后注入迁移失败，数据库恢复原版本与记录，工作空间文件哈希不变。

专项测试通过。结合已有原子写入、模型取消、平台超时恢复和打包桌面读写验证，完成 8.4。测试使用临时项目与合成收据，不接触用户项目；SIGKILL 是存储进程故障注入，不是物理断电或真实平台灾备演练。
