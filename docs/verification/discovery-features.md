# 实际功能探索清单（0.1.29）

2026-11-26。用实际发现的功能目标替代固定新建/编辑十项进度；新建、编辑依然属于存在时应深度体验的功能，不再给首页等模块强加模板。

## 行为

功能项按模块和稳定名称增量更新，含目标、实际结果、剩余、阻碍、下一步以及页面/资料依据。状态为待探索、探索中、部分验证、已验证、受阻。发现依据必须来自本任务，更新原子校验；资料描述只能支持功能线索。已验证必须有页面结果且没有剩余或阻碍。业务写入结果绑定同功能操作和后续页面，不能借用其他功能的提交记录。

进度只计算完整验证的功能项 / 已发现功能项，单项为0或100，不推测部分完成比例；发现新项可让整体下降。不是整个产品的覆盖率。旧通用清单保留但不换算新进度，旧报告与已批准记忆保持不变；继续时通过历史摘要与当前页面梳理实际目标。

继续探索优先可执行缺口，受阻项保留具体条件。有可执行项时拒绝finish并要求继续；连续三次提前结束则明确暂停，保留清单，不假报任务完成。业务写入确认与防重放保持。模型提供的目标及验证结论仍需用户核对，宿主只能校验结构和记录关联，不能保证语义推断正确。

模块仅显示一份列表：展开功能查看细节和依据，展开阶段理解查看自动整理结果；去掉重复模块列表及整理100%。
