# 平台操作中断与恢复验证

2026-11-18，任务 6.8。针对当前已开放的首次发布与云效同步流程验证，不包含暂缓的原文合并。

| 故障 | 恢复结果 |
| --- | --- |
| 飞书创建成功但响应丢失 | 按稳定发布标记查询已有子节点，仅唯一匹配时继续，不重复创建 |
| 创建后查询暂不可见 | 保持待核对且无新写入；后续唯一匹配出现后可继续 |
| 正文追加成功但响应丢失 | 核对唯一标记、连续块类型及文字后继续，正文无重复 |
| 附件绑定成功但响应丢失 | 读回原块的素材 token，继续剩余步骤，不重复上传已确认素材 |
| 上传响应丢失且无可核实 token | 保持待核对，禁止再次上传或声称发布完成 |
| 附件下载核对时断网 | 保留阶段收据；恢复后重做读取并继续缺失阶段 |
| 退出时记录仍为 running | 新工作流实例将其展示为待核对，不启动自动重放 |
| 云效写入响应丢失 | 仅 GET 核对目标状态，PUT 总数保持一次 |
| 云效读回不符 | 保持待核对，飞书成功记录不回滚、不重建 |
| 云效配置/状态变化 | 旧计划不能执行，需重新核对 |

19 项发布/云效专项测试通过（10 项发布、9 项云效），含重建工作流实例后的恢复和写入计数断言。模拟平台不会转发到真实租户。测试不能代替任务 8.3 的真实平台验收。

未知上传结果目前需要人工核对，没有提供强制重试入口。此限制是保留不确定结果而不是伪造恢复成功。
