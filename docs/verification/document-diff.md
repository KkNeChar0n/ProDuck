# 线上 PRD 差异评审（0.1.5）

2026-11-18。任务 6.4 完成，进度 34/47；6.5 合并前复核和 6.6 实际合并仍未完成。

## 实现范围

从当前项目已成功发布的需求文档进入“线上文档差异评审”。读取飞书最新根级文档块，核对当前项目连接和文档父节点，保存本地原始块快照与读取时间。按 Markdown 标题定位普通文字章节，包括一个飞书文字块内包含多个标题的情况；保留源块 ID 与文字偏移供后续定点合并使用。

选择文字范围后编辑内容并生成增删差异，未选中的内容保持原样。确认差异前重新读取线上文档，对目标块完整内容计算指纹；改变会清除批准并显示冲突。不同章节共享同一飞书块时采用保守规则，该块任意变化都会冲突；其他块的人工修改不会被覆盖，也不无故阻断本次纯文字评审。

评审记录和快照在项目 documents 下保存；校验本地原始快照与章节记录的一致性。批准仅针对差异指纹，独立于原型批准，不要求纯文字修订重新生成原型。本阶段只读远端、不合并；未来实际合并前仍必须再次读取、核对版本并处理写入竞争，因此不能将此次批准当作永久写入授权。

## 明确限制

仅支持 Produck 已发布文档，暂不接受任意飞书 URL 导入。普通文字可编辑；图片、附件、链接、原生格式标题、复杂格式和带嵌套子块的范围只读保留，不展开嵌套子树或转换格式。差异采用保留共同前后行、展示中间删除/新增范围的方式，不宣称最小编辑距离。

本轮未实现线上写回、共用原型更新和云效同步；没有真实平台写操作，没有调用用户真实模型。
