# 模块化探索与统一继续入口（2026-11-25）

目标版本：0.1.26。

## 行为

- 暂停和已有草稿都显示「继续探索」，读取界面设置的 2–120 步新预算；默认 40 步，移除恢复时固定补 5 步的规则。暂停任务开启新轮计数；有草稿的任务仍创建不可变分支，旧报告与批准记忆保留。
- 模型根据导航和资料列出最多 12 个模块，逐个深入。complete-module 在浏览器动作层之外触发模块自动整理；发生模块切换时先整理上一模块，再执行当前模块动作。预算结束会整理尚有新增依据的模块。
- 模块摘要单独调用项目模型，限定模块页面引用，综合观察、流程、新建/编辑清单和交接资料。校验失败保留阶段观察；继续时可重试。任务取消/断网/应用中断保留本地阶段记录，不发起额外的取消后模型调用。
- 状态与 Markdown 持久保存在任务文件的 modules 中；界面可展开查看。最终报告使用模块摘要并保留未访问模块和未覆盖项。已整理但有缺口标为阶段整理；自动整理不构成审核，不替换永久记忆。
- 「仅整理并结束本轮」保留为主动结束的可选操作，不是继续探索或保存阶段成果的前置步骤。

## 验证

- 类型、格式检查通过。119 项测试，118 通过、1 原生 Python 沙箱专项默认跳过。
- 覆盖：模块完成后自动摘要、跨模块执行顺序、预算结束后的最后模块整理、未访问计划保留、重复摘要缓存、外模块引用拒绝、失败重试、阶段快照和已有摘要保留。
- 暂停任务没有草稿时直接追加 60 步，保持已执行业务动作防重放。旧任务与已审核报告的续探隔离回归通过。
- Electron 无系统 CLI 桌面测试模拟模型中断，通过界面点击「继续探索」追加 60 步，自动模块摘要可见；继续完成原型/文档/模拟平台流程。

## 限制

模块划分、内容综合与覆盖评估仍依赖模型，必须核对引用和未验证项；本轮浏览器及桌面验收使用合成页面和模型响应，未声称真实业务系统已经完整探索。摘要使用有界证据和历史片段，明确标注截断；完整采集和模块记录留在项目工作空间。总步数仍受用户所设预算约束，不无限自动追加。

- 最终 DMG 临时提取副本验证通过，1968 个运行文件前后哈希一致；系统 CLI 不可用，仅替换临时副本测试入口，不修改发布包。
