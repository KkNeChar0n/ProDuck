# 内置工作流入口与适配范围

Produck 0.1.7，2026-11-18。

Skills 页面现在提供三个随应用编译的原生工作流入口：可操作原型、PRD 首次发布、PRD 差异评审。每项列出步骤、模型/平台使用条件、确认要求及限制，进入已有工作台或文档流程，保留当前项目。

这些入口复用 Produck 原生服务，不执行外部 SKILL.md 脚本，也不把导入技能默认升级为平台写入权限。原型制作使用随应用 Chromium 和模型适配器；PRD 使用批准版本截图、草稿服务和飞书首次发布适配器；云效状态同步独立确认；差异评审止于只读合并预检。原文合并继续暂缓。

这是参考已盘点工作流语义独立实现的目录与入口，不复制无明确再分发许可的原 Python 脚本。不宣称完整兼容 prd-feishu-edit，也不宣称 Agent 已能通过导入技能自动执行所有发布步骤。7.3 保留未完成，后续仍需将原生工作流能力接入受控 Agent 工具层；7.4/7.5 的运行时与脚本授权工作亦未勾选。

验证：Electron 测试逐个点击三个入口并返回，继续导入说明型 Skill 并执行现有任务；完整原型/文档/云效模拟闭环通过。截图见 desktop-builtin-skills.png。

新增 npm run test:desktop:no-cli：在 Electron 测试进程清空 PATH，断言 Node/Python/Codex/Claude 命令均不可执行，再运行同一桌面闭环。它检查运行期隐式 CLI 依赖，不能替代安装包在干净机器上的验收，也没有验证真实模型质量或真实平台权限。

无 CLI 模式实测通过：命令不可用断言成立，随后完成项目/模型、原型、PRD、导入技能、飞书发布和云效同步的模拟桌面闭环。全量 74 项自动化测试、类型检查、构建及格式检查通过。
