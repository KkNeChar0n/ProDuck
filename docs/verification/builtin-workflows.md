# 内置工作流入口与适配范围

Produck 0.1.8，2026-11-18。

Skills 页面现在提供三个随应用编译的原生工作流入口：可操作原型、PRD 首次发布、PRD 差异评审。每项列出步骤、模型/平台使用条件、确认要求及限制，进入已有工作台或文档流程，保留当前项目。

这些入口复用 Produck 原生服务，不执行外部 SKILL.md 脚本，也不把导入技能默认升级为平台写入权限。原型制作使用随应用 Chromium 和模型适配器；PRD 使用批准版本截图、草稿服务和飞书首次发布适配器；云效状态同步独立确认；差异评审止于只读合并预检。原文合并继续暂缓。

这是参考已盘点工作流语义独立实现的目录与入口，不复制无明确再分发许可的原 Python 脚本。不宣称完整兼容 prd-feishu-edit，也不宣称 Agent 已能通过导入技能自动执行所有发布步骤。7.3 保留未完成：本地生成能力已接入受控 Agent 工具层，线上差异准备与平台流程仍通过独立界面操作；7.4/7.5 的运行时与脚本授权工作亦未勾选。

验证：Electron 测试逐个点击三个入口并返回，继续导入说明型 Skill 并执行现有任务；完整原型/文档/云效模拟闭环通过。截图见 desktop-builtin-skills.png。

新增 npm run test:desktop:no-cli：在 Electron 测试进程清空 PATH，断言 Node/Python/Codex/Claude 命令均不可执行，再运行同一桌面闭环。它检查运行期隐式 CLI 依赖，不能替代安装包在干净机器上的验收，也没有验证真实模型质量或真实平台权限。

无 CLI 模式实测通过：命令不可用断言成立，随后完成项目/模型、原型、PRD、导入技能、飞书发布和云效同步的模拟桌面闭环。全量 74 项自动化测试、类型检查、构建及格式检查通过。


## 0.1.8：Agent 本地成果工具

工作流页无需导入即可选择两个内置技能，指令具有稳定内容指纹，任务保存所选版本快照。内置记录由应用提供，不写入项目的导入目录，也不扩大导入技能的权限。

- product_artifacts：当前项目原型、批准状态、截图与草稿元数据。
- generate_prototype：逐次批准后按已采集页面生成候选，可指定基线和修改要求。
- generate_prd：逐次批准后按已批准版本及对应截图生成本地草稿。
- read_prd：读取本项目草稿；长文明确标注截断。

没有注册自动通过原型、伪造截图检查、批准文档、发布或合并工具。生成调用复用现有项目隔离及版本检查。Agent 取消信号传入对应生成任务的 AbortController，避免取消后继续写成果。

78 项自动化测试通过，新增测试覆盖工具授权、项目范围、未批准版本、截图 ID 参数、取消无草稿和内置技能指纹。真实模型质量仍按用户要求跳过。

无 CLI 桌面验收通过：选择 builtin:prd，Agent 先列出成果再等待生成批准；批准前草稿数量不变，批准后只新增一份草稿，任务两步均成功，飞书节点与云效写入计数不变。截图：desktop-agent-prd.png。
