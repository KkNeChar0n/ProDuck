# Produck 工作台原型检查

检查日期：2026-11-17。对应任务：1.1、1.2。

## 运行与体验

直接打开 `prototypes/produck-workbench/index.html`，或执行 `npm run preview:prototype` 后访问 http://127.0.0.1:4173 。所有数据只保留在页面内存，刷新重置；无需真实 token。

1. 在客户列表体验搜索、空结果、重置和新增客户，检查必填校验与取消。
2. 点击「选择元素」，选中筛选区；右侧显示选中上下文。
3. 点击「试试添加状态筛选」并发送，体验新候选的状态和名称组合筛选。
4. 点击「通过此版本」，再点击「生成文档草稿」。
5. 继续输入“把标题改为「重点客户」”，确认新版本重新进入待确认状态，旧文档保留版本说明。
6. 在「撤销 / 恢复」中恢复初始版本；创建新项目并切换回原项目，检查上下文隔离。
7. 在模型配置中使用 demo-token 或 demo-fail 体验成功说明与鉴权失败反馈。

## 已验证

`python3 tests/prototype_smoke.py` 使用独立、临时 profile 的无头 Chromium，对本地演示页面完成以下检查：

- 未批准原型时禁用文档生成。
- 名称搜索空态、重置、新增必填与成功反馈。
- 状态筛选、原型通过、生成对应版本文档。
- 修改标题后创建新候选，旧文档提示版本不同。
- 恢复基线后原型内容正确。
- 模型设置格式、模拟鉴权失败及清除 token 输入。
- 项目创建、切换和模拟数据隔离。
- 元素选择上下文与任务取消。
- 1440×960 桌面与 390×844 窄屏截图，窄屏无页面横向溢出。
- 无 JavaScript 页面错误。

截图：`workbench-desktop.png`、`workbench-mobile.png`。已人工查看，桌面三栏与底部确认区完整，窄屏将对话区置于工作台下方。
