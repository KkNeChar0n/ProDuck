# 拖拽探索验收（2026-11-25）

目标版本：0.1.25。

## 行为

- 自动探索增加 drag(index,targetIndex,from?,to?)；位置为元素矩形内 0–1 坐标，默认中心，支持同一画布内不同起终点。
- 采集原生 draggable、拖动光标、canvas/SVG、区域及常见画布容器的索引、稳定路径与矩形；源目标需属于本次观察且命中视口内可见区域。视口外先滚动再重新观察。
- CDP 真实鼠标轨迹支持 Pointer/Mouse 交互；HTML5 拖放使用 Chrome 实际产生的 DragData，不伪造应用数据。拒绝本地文件拖放上传。
- 未知后果/业务写入按次确认；持久身份包含源目标，修改落点不会绕过写入防重放。取消及失败清理鼠标状态和拖放拦截，不宣称已发生的界面修改可回滚。
- 探索提示要求观察拖拽后的节点、位置、排序、属性联动，报告结合动作和前后采集。工具执行不等同业务成功。
- 图像能力已验证时为拖拽/画布页面附加截图；否则明确告知只有文字结构，未知画布内部对象保持未验证。

## 验证

- 类型检查和格式检查通过。114 项测试，113 通过、1 原生 Python 沙箱专项默认跳过。
- 新增单元测试覆盖源目标和坐标校验、未知后果确认、防重放身份、取消/异常鼠标释放，以及探索前后证据与截图传递。
- `npm run test:discovery:drag`：真实 Chrome 合成页面验证 HTML5 资源拖入及属性联动、Pointer 列表排序、Canvas 节点移动、视口外和过期目标拒绝、拖拽中取消、取消后继续、拒绝及执行后的重复业务动作阻止。
- `npm run test:discovery:forms`：真实 Chrome 表单读取、校验、查询、回车与跨入口提交保护通过。
