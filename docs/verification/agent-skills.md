# Agent、Skill 与原型增强验证

2026-11-17，macOS 26.3 arm64，Produck 0.1.1 测试版。

## 已实现及验证

- 受控 Agent：独立 utility process 请求模型，最多 12 个工具步骤，记录输入、结果、事件和检查点。支持资料列表/读取、记忆检索、原型读取、笔记保存和网页操作。写笔记和真实网页操作逐项批准，页面变化后旧批准失效。取消及重启中断保留记录；结果不明的操作要求人工核对，避免自动重放。
- 模型能力检测：文本、图片请求及无副作用的原生工具调用探测；支持 OpenAI-compatible 与 Anthropic。支持/不支持/未知分别展示，配置变更清空旧报告。图片探测仅证明接口接受图片，不证明视觉理解质量。
- Skill：导入目录及相对文本资源、来源和内容指纹、兼容性报告；工具映射是受限替代能力，Read 只读项目已导入资料，Write 只新建笔记，Glob 列举资料，Grep 搜索页面记忆。脚本、外部 CLI、未适配 MCP/宿主工具和非文本资源明确报告不支持。修改快照后必须重新导入。
- 原型：解析 HTML 并赋予稳定元素 ID，仅在唯一匹配时复用 ID。保存来源覆盖、元素差异、基础表单/展开/弹窗/滚动状态；不恢复密码、文件及任意 JS 内存状态。禁止外部素材与网络访问，保存的 HTML 内也嵌入 CSP。
- 人工交互检查：筛选/重置、弹窗、校验、取消、成功、空态，记录绑定原型内容哈希；失败撤销批准，新候选不继承记录。这不是自动判定生成页面正确。

## 验证证据

类型检查、42 项单元测试、生产构建通过。原生桌面测试使用临时 profile、虚构凭证和本地模拟 API，覆盖导入 Skill、选择技能、独立模型规划进程、工具调用、批准保存笔记及结果显示；原型测试覆盖选择模式隔离、状态恢复、六类交互及网络阻断。数据库 v1 → v2 迁移保留数据并先备份。

`desktop-agent.png` 为任务结果截图。模拟 API 验证流程与隔离，不代表真实模型任务质量；遵循用户要求未再调用其真实模型。
