# 探索进度与原型重试

0.1.27，2026-11-25。

## 查看与操作

在「工作台 → 理解产品」查看清单验证进度、本轮预算使用、当前模块和已整理模块数量。模块详情展示新建、编辑两个流程及各自五个检查项。模块阶段理解仍在「模块探索与自动整理」中查看；审核后才进入永久记忆。

清单只计入绑定当前探索有效页面依据的检查项：每项为 0% 或 100%，流程每项占 20%，模块每项占 10%；整体按已知模块的已验证项计算。新发现模块可能让整体比例下降。这不是整个产品功能的覆盖率，也不是模型思考耗时预测。步数预算使用率独立显示。历史步骤分别显示采集、决策和执行结果。

原型失败或取消后，在错误说明旁点击「重试原型生成」。入口绑定原任务并恢复其采集、基线及元素提示绑定，不读取后来修改的输入，也不覆盖历史版本；恢复页面后最近失败任务仍可重试。

## 长上下文

探索、模块整理与最终汇总使用有界 JSON 输入，保留元素原始索引，说明裁剪的含义。完整记录留在本地；超过请求预算会明确提示上下文超限，不再显示输入框字数错误。
