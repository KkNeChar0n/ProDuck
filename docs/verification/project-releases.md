# 项目下的产品版本

2026-11-19，Produck 0.1.13。

项目共享模型配置、工作空间、飞书应用凭证、云效连接、资料/记忆和技能。产品版本保存名称、飞书迭代父节点、原型修订、状态截图、PRD、批准、Agent/Python 执行结果和平台收据。侧栏选择项目后创建或切换版本，在版本设置保存并测试飞书目标。可以从同项目旧版复制原型为新候选，审批与发布记录不复制。

执行接口绑定固定产品版本 ID；保留旧 DTO 的 projectId 字段作为执行范围标识，以兼容已有收据。ProjectRepository.context 解析版本文件根目录，shared 解析项目共享资料和配置，不通过当前界面选择决定异步任务归属。数据库中的 project_id 继续保留真实项目 ID，原型和任务另存 release_id。

SQLite v3 升级前备份。旧项目生成默认版本（ID 沿用原项目 ID），旧文件不搬迁、内容不改写，旧飞书目标仅归入默认版本；后续版本文件位于 releases/<id>。新建项目不自动创建版本，用户显式创建。旧版应用拒绝打开升级后的数据库。

验证记录：

- 全量 87 项测试：86 通过，1 项原生 Python 沙箱专项按默认命令跳过。
- 新增版本专项覆盖新项目无版本拒绝执行、跨项目选择拒绝、同项目版本原型/批准/截图隔离、异步 Agent 完成仍归原版本、模型与云效继承、独立飞书目标、v2 数据及批准/收据迁移保留。
- 既有工作流测试使用模拟已迁移默认版本的夹具继续验证；新增版本专项使用真实新项目/新版本接口。
- Electron 无 CLI 模拟桌面闭环验证新项目版本内的原型、PRD、飞书发布、云效同步和 Python 执行；通过 UI 创建 V2、保存独立地址、复制为未批准候选、切回 V1 后检查发布记录保留。
- 0.1.13 DMG 提取副本在源码目录外、系统 CLI 不可用时通过同一闭环；1937 个运行文件前后哈希一致。
- 桌面截图：desktop-releases.png。

这些验证使用合成凭证与模拟 API，不代表真实平台验收。未恢复飞书原文合并，真实模型验证、干净机器安装和正式签名分发仍待完成。

## 2026-11-23：设置入口归属

0.1.14 移除“配置项目”和重复设置按钮，项目与版本选择器右侧各有独立齿轮；当前设置齿轮高亮。项目页显示共享模型、工作空间、飞书应用凭证和云效，版本页显示版本名、飞书迭代地址与原型复制。桌面验收确认项目页没有版本地址输入、版本页没有 App ID 输入，并继续通过完整模拟交付流程。类型检查、构建、格式与 OpenSpec 验证通过。

本机原 prd-feishu 技能按说明读取 ~/.prd-feishu/config.json 中的应用凭证，因此日常调用只需提供目标地址；Produck 的项目设置将这项依赖显式展示。未将本机凭证复制进仓库或安装包。

0.1.14 DMG 提取测试副本在无系统 CLI 环境中通过上述流程，1940 个运行文件前后哈希一致；仍为 ad-hoc 测试包，未公证，不替代真实平台与干净机器验收。
