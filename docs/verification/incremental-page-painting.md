# Produck 0.1.33：逐页采集与绘制

## 行为

- 每次页面观察与模块识别后绘制该页，再继续浏览。相同页面证据复用已有任务。
- 大页面按DOM边界拆为区域，每次序列化输入不超过16000字符；不把整个系统的HTML发送给一次生成调用。
- 模型输出截断或上下文超限时，区域最多进一步拆分4层；网络等临时错误最多追加3次重试。
- 完成区域落盘，失败、取消及重启保留输出。页面目录显示具体错误及“重试此页”，重试不重新操作浏览器。
- CSS使用区域scope，脚本查询绑定区域；宿主拼装HTML，原型仍使用原有无网络预览边界。
- 整理结束关联理解草稿，不重新整站绘图；理解与原型仍分别审核。
- 截图补充绑定模块页面并继承原型基线；每页修改只带本页证据。后台页面完成刷新目录，不连续切走正在编辑的页面。

## 验证

- 类型检查通过；完整自动测试141项通过、1项跳过。新增有界拆分、自动再拆分、取消、局部恢复、版本隔离和采集/绘制时序测试。
- Electron区域组装测试通过：两区域独立样式、按钮动作只作用于所属区域。
- 桌面fixture闭环通过：独立Chrome探索、原型目录、理解审核、截图粘贴补充与浏览器补采。
- 安装包验收包含主动注入页面生成失败、错误显示、点击“重试此页”并恢复成功。最终包运行时结果见 packaged-runtime.json。
- 测试模型使用本地fixture；真实模型的页面还原质量仍需实际体验，不将fixture结果视为真实产品视觉验收。
