# 桌面项目与模型集成验证

日期：2026-11-17。用户已确认原型方向，正式工作台按该布局接入真实状态。

## 完成内容

- 创建项目时通过原生文件夹选择器选定父目录，创建唯一子工作空间和初始记忆.md。
- SQLite 保存项目与连接地址；原子文件保存最后选择，项目的资料、连接和模型配置按 ID 隔离。
- 米白三栏 React 工作台连接真实项目状态，提供导航、空态、错误、重试与配置动作。
- Swift Security.framework 辅助程序将凭证存入 macOS 钥匙串。token 只经子进程标准输入传递，不置于命令行参数；项目与数据库仅含 UUID 引用。
- 模型配置、已保存配置连通性测试、OpenAI-compatible/Anthropic 文本流、取消及错误分类。更换供应商或 endpoint 必须重新填写目标服务 token。
- 导入 UTF-8 Markdown、TXT、HTML 原文件，保存时间、大小、SHA-256 和相对路径。不执行 HTML，也不自动发送给模型。

## 验证证据

- `npm run typecheck`、`npm run build` 通过。
- `npm test`：19 项通过，覆盖路径隔离、持久化、迁移恢复、资料校验、凭证引用、脱敏、模型错误分类和 SSE 分块/CRLF/截断/取消。

- `npm run test:desktop`：真实 Electron、临时 profile、原生选择器的受控测试替身、本机 HTTP 模型夹具。界面创建项目、切换、重载恢复、读记忆、导入资料、跨项目隔离、配置钥匙串、测试 API、发送文本和收到流式内容均成功。
- 截图：desktop-projects.png、desktop-model.png，来自运行中的 Electron。

文本问答当前每条独立发送，不保存历史，不构成完整 Agent 循环；任务执行、恢复和工具调用仍待实现。正式工作台尚未接入浏览器视图、原型编辑或平台写入。

开发构建需要本机 Swift 编译器；最终分发会随包携带编译后的钥匙串程序，用户不需要编译环境。安装包、签名及公证尚未完成。

桌面窗口如已打开，继续显示启动时版本；更新构建后需重启应用才能加载新增功能。请勿将浏览器中的旧界面原型当作真实模型设置入口。
