# 网页、原型与本地 PRD 验证

2026-11-17；macOS 26.3 / arm64；Electron 45。

## 已验证

- 类型检查、25 项单元测试、生产构建通过。
- `npm run test:workbench`：原生网页导航、筛选、重置、弹窗校验/取消、DOM/样式与 PNG 采集；预览不能通过 fetch、图片、弹窗或导航访问模拟生产接口，无 Node 或应用凭证桥。
- 元素选择运行于隔离脚本上下文；测试确认选择点击不触发模拟保存，退出选择模式后恢复交互。仅支持具有 `data-produck-id` 的元素及其后代，尚未验收真实生成模型能稳定保留所有 ID。
- `npm run test:desktop`：在临时应用 profile 和虚构钥匙串凭证下，通过本地模拟 API 完成创建项目、导入资料、模型配置、采集、原型生成、通过、prompt 修改、新候选不继承旧确认、任务记录。
- 原型不可变文件与内容哈希、项目隔离、版本源文件对比与恢复通过测试；尚无视觉差异叠图。
- 记忆保存观察来源、时间、未知规则；确认绑定文本哈希；新观察不会覆盖已确认内容，显示同 URL 的文本差异。文本差异不等同业务规则冲突的自动判定。
- 原型任务保存原始采集、基线和修改要求检查点；重启标记中断，显式重试新建任务；不自动重放外部操作。尚非通用 Agent 工具循环或跨平台恢复。
- 文档生成要求精确批准版本及匹配截图；未批准版本在调用模型前拦截。桌面测试保存当前批准原型的状态截图，生成本地 Markdown 草稿，审阅正文与图片，导出内嵌 PNG 的 HTML。新候选不能沿用旧版批准。
