# Produck 0.1.34：布局与工作台空间修复

## 问题及处理

- 原分区绘制丢弃父容器，并将所有区域纵向拼接。新计划保留父DOM的flex/grid布局和稳定插槽，区域回填原位置；二次拆分只替换对应插槽。旧快照缺少fixed偏移的侧栏/顶部栏/主内容结构转换为响应式网格。
- 采集补充固定偏移、flex伸缩、grid行列等布局属性。区域摘录去除重复继承样式，避免为无效样式增加大量子任务。
- 原型tab将绘制步骤、页面依据及生成重试合并至默认收起面板，摘要显示完成与失败数量。面板折叠后重新计算原生预览位置。
- 宽屏媒体查询覆盖了导航收起列宽；补充宽屏收起规则，工作区获得释放空间。
- “重新绘制此页”创建独立任务及候选版本，复用本页采集，不重新操作浏览器，不覆盖旧原型。

## 验证

- 类型检查与143项自动测试通过，1项既有测试跳过。
- Electron布局验收：1100px及1800px窗口的侧栏、顶部栏、主内容位置，区域独立样式与按钮交互。
- 桌面验收：1800px下收起导航后预览宽度增加；合并面板默认收起且包含页面依据，展开/收起改变原型区域位置；重绘生成新候选并保留旧版；截图补充闭环。
- 包内结果见 packaged-runtime.json。模型为本地fixture，真实模型的页面还原效果需重绘后实际检查。

## 体验

安装release/Produck-0.1.34-arm64-test.dmg后，在原型tab展开“绘制步骤与页面依据”，对旧页面选择“重新绘制此页”。新采集页面直接使用新布局。旧候选不会被静默改写。
