## ADDED Requirements

### 需求:技能导入与发现
系统必须支持导入 Codex / Claude 风格 SKILL.md 及相对附属资源并记录来源和版本。

#### 场景:导入技能目录
- **当** 用户选择包含说明与脚本的技能
- **那么** 展示名称、描述、资源和工具依赖，所有相对引用在技能包范围解析

### 需求:兼容性报告
系统必须在执行前显示可运行、需授权或不支持状态与具体缺失依赖。

#### 场景:宿主工具缺失
- **当** 技能依赖未适配的专用工具或外部二进制
- **那么** 阻止相关步骤并解释缺失能力，不宣称完整兼容或悄悄安装系统软件

### 需求:内置工作流开箱即用
内置原型与 PRD 技能必须使用随应用提供的工具和运行依赖。

#### 场景:无 CLI 环境调用
- **当** 用户在未安装 Codex、Claude、Node、Python 的机器调用内置工作流
- **那么** 在模型与必要平台配置有效时完成工作流，无需手动安装开发依赖

### 需求:技能权限与更新
系统必须展示脚本执行范围，首次启用敏感能力时获取授权，并在技能变更后重新检查。

#### 场景:技能升级增加权限
- **当** 新版本新增工作空间外访问或网络执行依赖
- **那么** 旧版本授权不得自动覆盖新增范围，运行前重新报告并获取授权
