## ADDED Requirements

### 需求:模型连接
系统必须支持 OpenAI-compatible 和 Anthropic 配置的 endpoint、model、token 及连接测试。

#### 场景:鉴权失败
- **当** 连接测试返回鉴权错误
- **那么** 显示可操作错误，不记录 token 或宣称连接成功

### 需求:模型能力匹配
系统必须在执行需要工具或图像能力的任务前检查适配器支持并提供失败说明。

#### 场景:不支持图像
- **当** 用户选择的模型不能接收截图
- **那么** 提示切换模型或使用明确标记的文本降级路径，不假称已分析图像

### 需求:凭证保护
凭证必须保存于系统钥匙串，并禁止写入项目内容、日志和生成原型。

#### 场景:保存配置
- **当** 用户输入平台或模型密钥
- **那么** 配置文件只保存引用，界面回显脱敏值，网页与原型无法读取密钥

### 需求:可恢复执行
系统必须持久化任务步骤、产出和中断状态，支持取消和恢复。

#### 场景:中途退出
- **当** 任务执行中退出应用后重新打开
- **那么** 显示中断步骤及恢复入口，已确认的外部写入不得盲目重放

### 需求:受控工具调用
工具必须绑定项目上下文并校验文件范围和权限，外部内容不得提高权限。

#### 场景:网页含指令
- **当** 页面文字要求读取其他项目文件或泄露 token
- **那么** 将其视为页面数据并拒绝越权工具调用
