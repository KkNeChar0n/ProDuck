## ADDED Requirements

### 需求:交接资料导入
系统必须支持 Markdown、纯文本与 HTML 交接文档并保存来源引用。

#### 场景:导入不支持格式
- **当** 用户选择未支持的文档格式
- **那么** 说明支持格式与转换入口，不将解析失败内容写成已理解事实

### 需求:登录网页采集
系统必须支持用户手动登录、Agent 体验指定页面并保存 URL、采集时间、页面状态与证据。

#### 场景:体验筛选页面
- **当** 用户完成登录并要求理解列表筛选
- **那么** 记录筛选条件、执行操作和可见结果，登录挑战交还用户处理

### 需求:有来源的记忆
系统必须生成可读取的记忆.md 索引及模块记忆，标记已观察、用户确认、推断或待验证。

#### 场景:遇到未知规则
- **当** 已看到页面但无法观察权限分支
- **那么** 将该分支标为待验证并引用现有依据，不写成确定业务规则

### 需求:记忆冲突与检索
系统必须按当前项目和相关页面检索记忆，保留冲突来源及更新时间。

#### 场景:新观察与旧确认冲突
- **当** 新页面行为不同于用户确认的旧规则
- **那么** 显示差异和来源，未经确认不得静默替换已确认规则
