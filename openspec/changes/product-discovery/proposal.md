## 为什么

单页手动采集无法让 Agent 理解产品的模块和流程，也没有将交接资料综合为可审核长期记忆。用户要求由 Produck 打开独立 Chrome，登录一次后自动探索并产出理解与可修改原型。

## 变更内容

- 增加独立 Chrome 产品理解入口，项目隔离登录资料，自动采集多页元素和流程证据。
- 结合已导入交接资料形成产品概览、模块、流程、依据、差异及待确认事项 Markdown。
- 草稿编辑审核通过后成为项目长期记忆；历史保留，重采集不覆盖批准版本。
- 基于审核通过的理解与多页面证据生成统一可操作候选原型，进入现有修改/通过流程。
- 保留手动浏览器采集作为补充工具，明确自动体验范围和未覆盖部分。

## 功能 (Capabilities)

### 新增功能

- `product-discovery`: 独立 Chrome 探索、资料综合、理解审核与原型生成闭环。

### 修改功能

无；现有 MVP 变更尚未归档，本变更新增独立能力并复用已有模块。

## 影响

新增桌面 Chrome 适配器、产品理解服务与 UI；复用模型客户端、工作空间、导入资料和原型生成器。需要本机 Chrome，无需 Node、Python 或 Agent CLI；没有 Chrome 时显示安装提示。凭证不读取、不导出，登录由用户完成。
