## 上下文

已有 Electron 浏览器、单页采集、页面观察记忆与原型版本服务。用户明确选择 Produck 打开的独立 Chrome，登录一次。保留旧单页工具，新增项目级理解任务；原型仍归启动时的产品版本。

## 目标 / 非目标

目标：自动导航体验，记录证据，结合资料产出可编辑审核的模块理解，批准后持久调用，基于同一理解生成多模块原型。
非目标：穷尽全部产品状态、绕过登录或权限、在真实产品自动提交业务变更、复制个人 Chrome 配置。

## 决策

- 使用系统 Chrome + CDP pipe，固定应用路径及项目独立 user-data-dir，不监听调试 TCP 端口，不依赖额外 CLI。会话保存在应用数据目录，不进入项目导出。由用户登录后点击开始。用户关闭浏览器则任务暂停；启动恢复保留历史采集，不自动重放操作。
- 单独的探索服务依赖小型 BrowserPort，模型只返回结构化动作和观察，不接受任意 JS。项目内同一时间一个任务。步数有界，取消传播到模型与动作。固定页面来源、元素索引与快照指纹，动作执行前核对。
- 自动模式只允许同站导航、常见查看/筛选/弹窗取消动作、搜索输入、选择器和滚动。网络层阻止非 GET/HEAD/OPTIONS 与明显变更路径，阻止下载/新窗口/权限请求；遇到需要提交或登录时交给用户，记录未覆盖范围。POST 查询可能被阻止，显式呈现而不声称流程已验证。手动接管时解除自动网络拦截。
- 新采集保存为证据而非确认记忆。理解报告按项目保存不可变修订；正文包含总览、模块、关键流程、证据、冲突和未验证项。模型输出结构化模块及依据 ID，由宿主校验，生成可编辑 Markdown。批准绑定正文摘要及证据摘要，活跃版本指针原子写入，旧版保留。普通页面观察不冒充长期理解。
- 已批准理解供项目记忆页及 Agent 检索；生成原型携带报告 ID/哈希，重新核对批准内容，拼接多页结构和报告，记录所有来源。仍使用现有候选/通过/元素修改/PRD 流程；生成失败不撤销已批准记忆，可重试。
- 首版不建设通用浏览器插件、后台服务或新数据库；拆分 Chrome 适配器、发现服务、记忆仓库与 UI。

## 风险 / 权衡

复杂产品、虚拟列表和跨域流程可能未完整探索，必须显示访问页面、步骤、预算与未覆盖原因；不保证只读 HTTP 方法就是业务无副作用，只自动操作明确查看用途的控件，写入转人工。模型可能推断错误，报告显式保留依据与待验证，用户审核后才成为长期记忆。长材料显示截断，不静默声称全部阅读。
