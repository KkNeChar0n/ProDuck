## 上下文

已有 Electron 浏览器、单页采集、页面观察记忆与原型版本服务。用户明确选择 Produck 打开的独立 Chrome，登录一次。保留旧单页工具，新增项目级理解任务；原型仍归启动时的产品版本。

## 目标 / 非目标

目标：自动导航体验，记录证据，结合资料产出可编辑审核的模块理解，批准后持久调用，基于同一理解生成多模块原型。
非目标：穷尽全部产品状态、绕过登录或权限、未经确认提交真实业务变更、复制个人 Chrome 配置。

## 决策

- 使用系统 Chrome + CDP pipe，固定应用路径及项目独立 user-data-dir，不监听调试 TCP 端口，不依赖额外 CLI。会话保存在应用数据目录，不进入项目导出。由用户登录后点击开始。用户关闭浏览器则任务暂停；启动恢复保留历史采集，不自动重放操作。
- 单独的探索服务依赖小型 BrowserPort，模型只返回结构化动作和观察，不接受任意 JS。项目内同一时间一个任务。步数有界，取消传播到模型与动作。固定页面来源、元素索引与快照指纹，动作执行前核对。
- 自动模式支持同站导航、通用控件、输入、选择器、键盘与滚动；允许 POST 查询。明显变更路径、GraphQL mutation 与其他写入方法需要当前动作确认。业务提交由宿主单次确认后 Agent 执行；登录由用户完成。阻止下载、新窗口和权限请求，记录未覆盖范围。手动接管时解除自动网络拦截。
- 新采集保存为证据而非确认记忆。理解报告按项目保存不可变修订；正文包含总览、模块、关键流程、证据、冲突和未验证项。模型输出结构化模块及依据 ID，由宿主校验，生成可编辑 Markdown。批准绑定正文摘要及证据摘要，活跃版本指针原子写入，旧版保留。普通页面观察不冒充长期理解。
- 已批准理解供项目记忆页及 Agent 检索；生成原型携带报告 ID/哈希，重新核对批准内容，拼接多页结构和报告，记录所有来源。仍使用现有候选/通过/元素修改/PRD 流程；生成失败不撤销已批准记忆，可重试。
- 首版不建设通用浏览器插件、后台服务或新数据库；拆分 Chrome 适配器、发现服务、记忆仓库与 UI。

## 风险 / 权衡

复杂产品、虚拟列表和跨域流程可能未完整探索，必须显示访问页面、步骤、预算与未覆盖原因；不保证只读 HTTP 方法就是业务无副作用，普通控件自主操作，识别出的写入须单次确认。模型可能推断错误，报告显式保留依据与待验证，用户审核后才成为长期记忆。长材料显示截断，不静默声称全部阅读。

## 2026-11-24：授权自主操作

用户明确要求授权后自主操作，不接受每个未知控件转手动。开始/继续按钮明确授予当前站点浏览器操作权限；移除名称白名单，支持普通可交互元素、表单输入与键盘操作。危险控件、表单提交及模型声明的写入/未知后果由宿主单次确认，确认后仍由 Agent 执行。网络不再一刀切阻止 POST，以兼容查询型 API；明显变更接口与非读取方法仍需要本次动作确认。该机制是应用层操作约束，不能声称完整只读网络沙箱。

操作失败写入记录后重新观察、换路，连续失败达到上限则整理已有依据，不要求用户逐控件接管。已尝试的业务写操作不自动重放；拒绝的操作在本次会话中不重复弹窗。现有登录仍由用户完成，审核长期记忆仍保持显式确认。

## 2026-11-24：表单状态和提交身份

采集普通字段当前值、关联标签、required 与原生 validity，不采集密码、文件或隐藏字段。查询表单须有搜索语义、无业务变更控件及明显写入目标；模型声明不能解除业务确认。回车使用完整 CDP 字符事件语义。

业务提交身份绑定站点页面与表单，不随保存按钮/回车入口改变，不用修改字段来绕过防重放。原生无效表单在任何输入/点击事件派发前直接返回“未执行，校验未通过”，不占用业务尝试记录；其他拒绝、结果不明或已执行情况保留记录。旧任务若没有表单身份信息，保守拒绝继续业务提交，新的理解任务不受旧格式限制。

## 2026-11-25：默认体验新建与编辑

每个已识别模块默认跟踪新建、编辑，分别记录入口、字段与默认值/回填、校验约束、取消和保存结果。覆盖由模型依据实际采集评估，宿主验证引用；保存结果必须有同模块同流程的真实已执行业务操作及后续观察，不能仅凭动作返回即标记成功。尚未覆盖须明确原因，未找到入口不等于功能不存在。最多两次纠正过早结束，之后仍未满足则产出明确不完整的报告，不无限循环。

覆盖记录随任务持久化并进入最终 Markdown，不由报告模型覆盖。默认 40 步，最大 120；预算不足如实记录，用户可以缩小范围。常规探索不默认执行删除。编辑优先使用本轮新建测试记录或用户指定测试数据；真实业务提交保持单次确认。复用表单的对话框标题纳入业务身份区分新建/编辑，不以字段值变化绕过防重放。旧任务没有覆盖记录时继续时建立清单，不推断历史已完成。

## 2026-11-25：已结束轮次继续探索

继续探索创建关联的新任务快照，深拷贝原轮次的采集、步骤、资料及覆盖清单，继承业务防重放记录。原任务不再修改，因此旧报告的依据哈希和已审核记忆继续有效。新轮次 budget 为已有状态数加用户选择的新增步数（2–120）；roundStart 标识新增部分，界面同时展示本轮和累计状态。跨轮总量不受单轮120限制，模型报告仅使用近期页面与步骤的有界摘要，完整证据仍在任务文件。

上轮最新报告作为参考，不当成已审核事实。提示优先补齐缺失项，历史阻碍需重新判断但不能绕过拒绝与防重放。续探只接受当前项目已生成草稿的任务，运行时不可并发。新轮草稿仍须独立审核。重新探索独立开始，不继承覆盖与操作记录。

## 2026-11-25：拖拽

动作绑定本次观察的源/目标索引及元素内归一化位置，默认中心。采集 draggable、拖动光标、画布和区域语义及边界；不接受任意 JS。CDP 鼠标轨迹支持指针拖动，原生 HTML5 拖放使用拦截得到的真实 DragData。坐标必须在视口内、命中目标且与观察一致，不自动滚动后盲拖。取消和异常清理按键与拦截；结果不明不得自动重放业务操作。未知后果和写入需确认；身份含源目标稳定路径。每次动作后的页面证据用于效果核对，事件派发不等于业务成功。图像能力已验证时探索可携带画布截图，否则明确仅有结构化文字依据，不猜画布内容。

## 2026-11-25：模块化探索与统一继续入口

所有继续入口命名为继续探索，均使用界面设置的2–120步追加预算。暂停且无报告的任务可在原记录上开启新轮计数；已有报告继续使用不可变分支。旧resume接口默认40步，移除固定补5步逻辑。

模型先列出从导航或资料识别的模块计划，逐个深入；模块结束使用complete-module动作触发自动整理，再进入下一模块。模块切换时自动整理上一模块，预算结束时整理剩余模块。单独模块摘要调用只使用该模块采集、观察、覆盖和交接资料，校验引用；摘要落到任务文件，不成为已审核记忆。界面展示待探索、体验中、整理中、已整理/阶段整理及整理失败。失败或取消保存有来源的本地阶段记录，后续继续可重试；不同模块摘要互不覆盖。续探继承模块状态，已整理无新依据的模块不重复调用。最终报告结合模块摘要与未访问计划；永久记忆仍需人工批准。

## 2026-11-25：进度与重试

原型进度事件携带runId，错误旁重试绑定对应检查点；重启读取最近任务，不能把旧失败任务误当新失败。探索百分比基于模块新建/编辑10个检查项，单项仅0或100，未知和拒绝不计完成；整理进度与体验覆盖分开，预算用量单独标注。模型生成无已知总量，显示真实阶段而不编造递增百分比。上下文分段限制JSON长度，保留索引和依据ID语义，完整记录仍在本地；各模型阶段总输入控制在50000字符以内，超限错误明确指出内部上下文。
